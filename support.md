## Getting help

For package behaviour, reproducible bug reports, and feature requests, use the
issue tracker belonging to the relevant implementation:

- [DigiMicPy issues](https://github.com/DigiMicOrg/DigiMicPy/issues)
- [DigiMic.jl issues](https://github.com/DigiMicOrg/DigiMic/issues)
- [Platform website issues](https://github.com/DigiMicOrg/DigiMicOrg.github.io/issues)

For a general project enquiry, contact Yan Zhu at
`yan.zhu [at] imperial.ac.uk` or use the public links on the
[Team page]({{ '/team/' | relative_url }}).

## Contributing

Contributions may include code, model extensions, reproducible examples,
datasets, documentation, or research questions that expose a missing workflow.
Open an issue before beginning a substantial implementation so equations,
units, state layout, and repository ownership can be agreed first.
